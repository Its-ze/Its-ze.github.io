Neural Forge save recovery

Use this page in the same browser, browser profile and device where you played Neural Forge. Repeat on any others you used. Private browsing data may already have been cleared by your browser.

This page downloads a copy only when you click a button. It does not delete or change your saved data, and it does not upload it. Store the downloaded files somewhere safe.

1. Download your saved data

If a button says no data was found, it only means that entry is absent in this browser profile on this device. Check every browser and device you used. Progression is exported for safekeeping; the desktop app has no separate progression-only import.

2. Open and verify your project

  1. Get Neural Forge 0.5.6 from the ITSZ App Store or release downloads.
  2. In the desktop app choose Open project and select the downloaded project file. If necessary, try the previous project backup.
  3. Check the experiment, archive and replay you expect; then save a new desktop copy. Keep the original downloads and progression backup too.

Older settings-only saves can open with unsupported trained counters reset. If a file fails to open, keep it unchanged for recovery. Do not clear browser data until your backups are verified.
